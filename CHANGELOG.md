## [0.1.0] - 2026-08-31

### Added

- Desktop pet cat window (borderless, topmost, transparent background)
- Click to open/close the cat's mouth
- Drag & drop files onto the cat to send them to the recycle bin (tkinterdnd2)
- System tray icon (pystray) with Show/Hide and Quit menu
- Tray icon mirrors the cat's open/close state
- Multi-size .ico icons for tray use
- `pop-trash` console command (pip install -e .)
